# Medical Appointment Booking

A fast, simple React application for booking medical appointments. It features a Patient Portal for booking slots and an AI Assistant, plus a Staff Dashboard for managing schedules.

The app uses a mock database (`localStorage`), so it runs entirely in your browser with zero backend setup required.

## Quick Start

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the app:

   ```bash
   npm run dev
   ```

3. Open your browser to `http://localhost:5173`.

## Tech Stack

- React 19 + Vite
- Tailwind CSS v4
- React Hook Form
- date-fns
